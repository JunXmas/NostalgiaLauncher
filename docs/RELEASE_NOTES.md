# Nostalgia 1.2.0rc39 — Server Forgotten Worlds lên trang chủ

Server Forgotten Worlds giờ có thẻ lớn ngay đầu trang chủ, và launcher báo khi
modpack của server có bản mới.

## Trang chủ

- Ô lớn đầu trang chủ thành băng trượt có nút ‹ › và chấm chuyển trang. Slide
  đầu là server **Forgotten Worlds** với ảnh cảnh thật từ server tự đổi mỗi 5 giây:
  - chưa có bản chơi server: nút **Tạo bản chơi server** mở hộp tạo với
    Forgotten Worlds chọn sẵn;
  - đã có: nút **Vào server** vào thẳng `snow.pikamc.vn:25079`;
  - modpack có bản mới: nút đổi thành **Cập nhật modpack** và hiện phiên bản
    đang dùng / bản mới.

## Thông báo modpack

- Lúc mở launcher (và khi bấm kiểm tra), nếu kênh modpack có bản mới hơn bản
  chơi đang cài, launcher hiện thông báo kèm chuông (nếu bật). Mỗi phiên bản
  chỉ báo một lần trong phiên.

## Modpack Forgotten Worlds 1.0.5 (cài kèm)

- Thêm Naturalist (voi, hươu cao cổ, ngựa vằn, sư tử, gấu, cá sấu, rắn, ốc
  sên…) — bản port riêng cho 1.21.11, phải có ở cả client và server.
- Gói tài nguyên Việt hoá bật sẵn; bản chơi mới mặc định tiếng Việt.
- Bản chơi đang có: bấm **Cập nhật modpack**. Thế giới, bản đồ và cài đặt cá
  nhân được giữ.
